# 幻梦圆环 · Windows 版

在 Photoshop 画布上按住 **Alt 再点右键**（或按 **Ctrl+Alt+R**），弹出一个饼菜单圆环，
不离开画布就能完成「生成 / 改参数 / 套预设 / 读选区」。

---

## ⚠️ 先读这一段

**这份代码从来没有编译过。** 一行都没有。

写它的机器是 macOS，而 WPF（`net8.0-windows`）是 Windows-only 的目标框架，
在 Mac 上编译不了。所以：

- 我按 `SPEC-ring-config.md` 把圆环的几何、协议、配置 1:1 移植过来了
- 但 **P/Invoke 签名、XAML 语法、DPI 坐标换算** 这些只能等编译器告诉你
- 第一次 `dotnet publish` 大概率会有报错，**这是预期内的**

有报错就把从 `error` 开头的那几行复制给我，我来修。

## 一、编译

### 1. 装 .NET 8 SDK

https://dotnet.microsoft.com/download/dotnet/8.0

选左边的 **SDK x64**，不要选 Runtime（Runtime 只能跑，不能编译）。
装完**关掉所有命令行窗口**再继续（环境变量要重新加载）。

### 2. 双击 `一键构建.bat`

它会检查 SDK、编译、然后告诉你程序在哪：

```
publish\HuanmengRing.exe
```

## 二、第一次运行

双击 `publish\HuanmengRing.exe`。

**托盘（右下角）会出现一个圆环图标** —— 这就是它，没有主窗口。

### 不需要任何权限

这一点比 macOS 版舒服得多：

| 平台 | Alt+右键 | 快捷键 |
|---|---|---|
| macOS | 要「辅助功能」权限，还要重启 | 不需要 |
| **Windows** | **不需要** | **不需要** |

`WH_MOUSE_LL` 低阶钩子和 `RegisterHotKey` 在 Windows 上都不需要管理员权限、
也不需要任何系统授权。装完直接用。

### 加载 Photoshop 插件

圆环只是个「遥控器」，实际的生成/修图都由 PS 插件执行。所以插件也要装上：

1. 打开 **UXP Developer Tool**（Windows 版）
2. **Add Plugin** → 选 `Dream-ps-ai` 文件夹
3. **Load**
4. 在 Photoshop 里打开：**插件 → 幻梦AI 修图插件**

托盘图标变成 **◎** 就说明连上了（**○** = 没连上）。

> 插件本身是跨平台的，**和 macOS 用的是同一份代码**，不用改。
> UXP 的桥接部分（`ring-bridge.js`）连不上时会静默重连，不影响插件其他功能。

## 三、圆环怎么用

| 操作 | 作用 |
|---|---|
| **Ctrl+Alt+R** / 画布上 **Alt+右键** | 唤出（按一下就松手，圆环留在原地） |
| 移动鼠标 | 高亮指针指向的扇区 |
| **左键点击** | 确认；带子菜单的会进下一级 |
| **1 ~ 9** | 直接选中第 n 个扇区 |
| **← / Backspace / Delete** | 返回上一级 |
| **Esc** / 点环外 | 关掉 |

### 六个扇区

| 扇区 | 作用 |
|---|---|
| **生成** | 按当前面板参数跑一次生成 |
| **参数** | 改模型 / 分辨率 / 数量（面板同步） |
| **预设** | 选分类 → 选预设，自动填提示词 |
| **对话** | 进下一级：模型 / 快捷提问 / 打字提问 / 看回复 / 新对话 / 打开面板 |
| **读选区** | 把选区像素读进插件 |
| **关闭** | 收起圆环（**不会退出程序**，退出在托盘菜单里） |

带子菜单的扇区，外缘有朝外的小三角。

#### 对话 · 打字提问（支持中文输入法）

点「打字提问」会在圆环下方弹出一个输入条，**可以直接用微软拼音、五笔、手写**：

1. 输入条出现时焦点已经在里面，正常打字即可
2. 输入法候选窗出现在输入条那里，用它选词
3. **回车发送**；输入法正在组字时回车是「选词」，不会误发半截拼音
4. 回复显示在同一个气泡里；再按回车接着问下一句
5. **Esc 关掉气泡**（组字中的 Esc 先给输入法取消候选）

> **为什么打字时 Photoshop 会失去前台焦点**：输入法（TSF）只能挂在**前台窗口**上，
> 这是系统的硬性要求，绕不过去。关掉气泡时助手会把前台还给 Photoshop。

> **为什么打字期间圆环不吃键盘**：圆环的键盘钩子会吞掉 Esc 和数字键
> （数字是直选扇区用的），而这两个正是输入法用来取消组字 / 选候选词的。
> 气泡一开，钩子就卸掉；同时也不响应「点环外关闭」——
> 否则用鼠标点一下输入法候选词，整个圆环就被当成「点了 Photoshop」收掉了。

## 四、偏好设置

托盘图标 → **偏好设置…**

四个标签页：**外观 / 交互 / 内容 / 高级**，顶部有实时预览，改完立刻生效、关窗自动保存。

- **外观** —— 环大小 / 厚度 / 间隙 / 弹出距离 / 透明度 / 动画 / 投影 / 字号 / 全套配色（含 5 套预设）
- **交互** —— 热键 / Alt+右键开关 / 悬停即高亮 / 数字键 / Esc / 方向线
- **内容** —— 六个扇区的**重命名 · 显隐 · 排序**
- **高级** —— 桥接端口 / 配置文件位置 / 导入导出 / 恢复默认

## 五、和 macOS 版的关系

**配置格式和通信协议完全一致**，写在 `SPEC-ring-config.md` 里，两边各自独立实现。

| | macOS | Windows |
|---|---|---|
| 配置文件 | `~/.huanmeng-ring.json` | `%USERPROFILE%\.huanmeng-ring.json` |
| 内容 | **同一份格式** | **同一份格式** |
| 桥接 | `ws://127.0.0.1:8799` | 同 |
| 默认热键 | ⌥⌘R | Ctrl+Alt+R |
| 配置里的 `cmd` | ⌘ 键 | Win 键 |

**配置文件各存各的**，想两边一致就在偏好设置 → 高级里「导出配置」，
拷到另一台机器再「导入配置」。

> ⚠️ 从 Mac 导入配置时注意：里面如果写着 `cmd` 组合（比如 `alt+cmd+r`），
> 到 Windows 上会变成 `Alt+Win+R` —— **Win+R 是系统的「运行」对话框**，
> 注册会失败。到 Windows 上把热键改成 `ctrl+alt+r` 之类。

## 六、排查

### 托盘看不到图标

进程没起来，或者被折叠了（点托盘的小箭头展开）。

### 圆环弹出来了，但显示「未连接插件」

托盘菜单 → **自检…**，看是哪一条：

| 自检说什么 | 原因 | 怎么办 |
|---|---|---|
| 插件未连接（端口空闲） | PS 里插件没在跑 | UDT 里 Load `Dream-ps-ai`，再在 PS 里打开面板 |
| 检测到 N 次状态解析失败 | 有别的客户端在抢端口 | 关掉多余的插件实例 |
| 端口被占用，插件没连上 | 有另一个圆环在跑 | 任务管理器里结束掉多余的 `HuanmengRing.exe` |

### Alt+右键没反应

1. **Photoshop 必须在最前面** —— 这是刻意的，否则你在任何软件里按 Alt+右键都会弹圆环
2. 系统里根本没装 Photoshop 时是**不限制**的（方便单独试圆环）
3. 直接改用 **Ctrl+Alt+R**

### Ctrl+Alt+R 没反应

被别的软件占了这个组合。托盘 → 偏好设置 → 交互 → 全局热键，换一个。
（自检会告诉你到底是「已注册」还是「被占用」）

### Alt+右键把 Photoshop 的右键菜单也带出来了

不该发生 —— 触发时那一下右键事件是被吞掉的。
如果真出现了，说明鼠标钩子没装上，看自检里的说明。

### 几个刻意的设计

**为什么 WebSocket 服务端是手写的，不用 `HttpListener`**
`HttpListener` 的 URL 前缀要在 HTTP.SYS 里注册（`netsh http add urlacl`），
非管理员账号直接抛「拒绝访问」，报错还很难懂。手写握手 + 帧解析不到 200 行，
没有任何系统前置条件。

**为什么窗口显隐不走 `Window.Show()/Hide()`**
WPF 的 `ShowActivated` **只在第一次 `Show()` 时生效**，之后再 `Show()` 会抢走
Photoshop 的焦点 —— 焦点一丢，PS 当前的工具/选区状态就没了。
所以启动时 `Show()` 一次建好 HWND，之后一律用 `SetWindowPos` 的
`SWP_SHOWWINDOW` / `SWP_HIDEWINDOW`。

**为什么位置用物理像素而不是 `Window.Left/Top`**
混合 DPI 下 `Window.Left` 的坐标系是「按主屏缩放的 DIP」，副屏会错位。
`Reposition()` 用 `GetDpiForMonitor` 拿到目标屏的缩放系数，
再用物理像素的 `SetWindowPos` 定位。

**为什么键盘钩子只在圆环显示期间安装**
圆环窗口是非激活的，收不到键盘；而常驻键盘钩子一旦有 bug 会影响平时打字。
所以只在圆环开着的时候装，一关立刻摘掉。

**为什么吸取了 macOS 版的一个崩溃教训**
切换层级时必须重置 `hoverIndex`。新一层块数更少时，旧索引会让绘制代码
访问 `segments[hoverIndex]` 越界 —— macOS 版为此崩过一次
（`Swift runtime failure: Index out of range`）。`RingCanvas.Level` 的 setter 里
第一件事就是 `_hoverIndex = -1`。
