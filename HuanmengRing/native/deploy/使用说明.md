# 幻梦AI · 幻梦圆环

一个常驻菜单栏的小助手。按 **⌥⌘R**（或在 Photoshop 画布上按住 **⌥** 点右键），
弹出一个饼菜单，不离开画布就能干活。

**它有两种用法，装完之后按需选：**

| | 需要什么 | 能干什么 |
|---|---|---|
| **当独立软件用** | 只要这个助手 | 对话（支持中文输入法）、AI 生图、结果自动存盘 |
| **配合 Photoshop 用** | 再装插件（见文末） | 上面全部 **+** 读选区、按选区出图、结果贴回图层 |

两种可以同时用：PS 开着就走 PS（结果能贴回文档），PS 关了助手自己干活。

---

## 一、装（双击一次）

把整个文件夹拷到那台 Mac 上，**双击 `一键安装.command`**，按提示做。它会自动：

1. 检查环境
2. 把助手装到 `~/Applications`
3. 设置开机自启并启动
4. 引导你完成「辅助功能」授权（**等你在系统设置里勾上，勾完自动继续**）
5. 这台机器上如果有 Photoshop 和 UDT，顺手把插件也加载进去
6. 跑一遍自检，报告哪一项有问题

> **macOS 会拦一下**：没经过 Apple 开发者签名，提示「无法打开」时
> **右键点它 → 打开**，再确认一次就行。
> 已经装好了打不开的话，跑一句：
> `xattr -dr com.apple.quarantine ~/Applications/HuanmengRing.app`

## 二、第一次用要填密钥（只做一次）

助手调 AI 接口要用你自己的密钥。两种填法：

**A. 另一台机器上插件已经配好了** → 在 PS 里打开插件，再点菜单栏
**◎ → 从插件导入接口配置**，一键拉过来。

**B. 手上没有插件** → 菜单栏 **◎ → 打开配置文件**，填 `config.api`：

```json
"api": {
  "grsApiKey": "sk-…",           // 必填。GRS 密钥，对话和生图共用
  "grsRegion": "domestic",        // domestic = grsai.dakka.com.cn
  "imgModel": "nano-banana-fast",
  "imageSize": "1K",              // 1K / 2K / 4K
  "chatModel": "grs/gpt-5.5",
  "outputFolder": ""              // 留空 = ~/Pictures/幻梦AI
}
```

改完**重启助手**（菜单栏 ◎ → 退出幻梦圆环，再打开 App）。

验证通不通：

```bash
~/Applications/HuanmengRing.app/Contents/MacOS/HuanmengRing --chat-test
```

> 这个文件里是明文密钥，权限已经设成 600（只有本机能读）。

## 三、怎么用

### 唤出圆环

| 操作 | 需要权限 |
|---|---|
| **⌥⌘R** | **不需要** |
| 按住 **⌥** 再点**右键** | 辅助功能 |

**⌥右键在任何程序里都能用**（不限于 Photoshop）—— 助手现在是个独立软件，
PS 没开时也得能唤出来。普通右键（不带 ⌥）任何情况下都不受影响。

> 想换快捷键：偏好设置 → 交互 → 热键，填 `alt+r` 就是 ⌥R。
> 不过光秃秃的 ⌥R 是个正常打字组合（打出 ®），全局接管后所有软件都按不出它了，
> 建议保留 ⌘ 或 ⌃。

按一下就松手，**圆环留在原地**。移动鼠标高亮，**左键点击**确认，
带子菜单的扇区外缘有个小三角。`1~9` 直接选第 n 个，`Esc` 关掉。

### 六个扇区

| 扇区 | 干什么 |
|---|---|
| **生成** | 出图。PS 开着按面板参数出图并贴回文档；没开就自己出图，存到 `~/Pictures/幻梦AI` |
| **参数** | 改模型 / 分辨率 / 数量 |
| **预设** | 选分类 → 选预设，自动填提示词 |
| **对话** | 进下一级：模型 / 快捷提问 / **打字提问** / 看对话 / 新对话 / 打开面板 |
| **读选区** | 把选区像素读进插件（需要 PS） |
| **关闭** | 收起圆环（**不会退出助手**） |

### 在圆环里直接对话（支持中文输入法）

点「对话」→「**打字提问**」，圆环下方弹出一个输入条：

- **直接用拼音 / 双拼 / 手写打字**，候选窗就在输入条那里
- **回车发送** —— 输入法正在组字时回车是「选词」，不会误发半截拼音
- 问过一句后它变成**对话窗**：上面是整段来回（可滚动，往上翻能看到之前聊的），
  下面还是输入框，接着问就行
- **按住气泡空白处可以拖**，拖到哪儿就待在哪儿
- `Esc` 关掉（组字中的 Esc 先给输入法取消候选）

> 打字时 Photoshop 会暂时失去焦点 —— 输入法只能挂在前台窗口上，这是系统的规矩。
> 关掉气泡时助手会把焦点还回去。

### 六个格子在独立模式下分别是什么

没插件时圆环不是残废的 —— 每一格都有自己的数据源：

| 格子 | 没插件时 |
|---|---|
| **生成** | 展开：纯文字 / 导入图片 / 截屏 / 用上次的图 |
| **参数** | 模型 / 尺寸 / 张数，**写进助手自己的配置**（`config.api`），立刻生效 |
| **预设** | 助手自己的预设库（`~/.huanmeng-presets.json`，首次自动装 8 条） |
| **对话** | 模型 / 快捷提问来自 `config.api`；打字提问、看对话、新对话都能用 |
| **读选区** | 没有 PS 选区可读，换成「导入图片 / 截屏」—— 同一件事，换个来源 |
| **关闭** | 不变 |

**预设从哪来**：插件的全部预设（68 条 / 23 个分类）**已经打包进 App**，
新机器装上就自带，不用先连插件导一次。存放在 `~/.huanmeng-presets.json`，
可以手改、也可以从插件导入覆盖。

> 打包的那份在 App 的 `Contents/Resources/presets.json`。
> 更新它：把新的 `yushe.json` 拷成 `native/HuanmengRing/Resources/presets.json`，
> 并把 `PresetStore.seedVersion` 加一（用户那边才会换新）。

**从插件导入**（菜单栏 ◎ →「从插件导入接口配置」）会把密钥、模型、
**对话模型清单、快捷提问、以及全部预设**一起拉过来 —— 插件里配过的东西，
助手这边不用再配一遍。

> 预设存在 `~/.huanmeng-presets.json`，格式 `[{category, name, prompt}]`，
> 可以手改、也可以直接从插件导入覆盖。

### 参考图和预设可以一起用

最常见的用法就是**截一张图 + 套一个预设** —— 比如截下人像，套「一键修脸」。
顺序随便，两个都会留着：

**先截图再套预设**
1. 圆环 → 生成 → 截屏 → ⇧⌘4 截一张
2. 气泡上会写「参考图：xxx · **Esc 回圆环可选预设**」
3. 按 Esc，再唤出圆环 → 预设 → 人像精修 → 一键修脸
4. 提示词被预设填好，**参考图还在**，回车生成

**先套预设再截图**
1. 圆环 → 预设 → 选一个（提示词填进气泡）
2. 按 Esc → 圆环 → 生成 → 截屏 → 截一张
3. **刚才的提示词不会被清掉**，参考图也挂上了，回车生成

气泡底部那行会同时写着「参考图：xxx · 预设：yyy」，一眼能看出挂了什么。

> 想回到纯文字：圆环 → 生成 → 纯文字。它只丢掉参考图，
> **不会清掉你已经打好的提示词**（那多半是刚套的预设，清了就白套了）。

### 独立出图

圆环 →「生成」→ 弹出输入条 → 写提示词 → 回车。
出好的图弹一个结果窗：能看、能拖、能「另存为」、能「打开文件夹」。

---

### 独立出图：纯文字 / 导入图片 / 截屏

没有插件时点圆环的「生成」，会先展开一层问你**要不要参考图**：

| 选项 | 干什么 |
|---|---|
| **纯文字** | 只用提示词出图 |
| **导入图片** | 弹文件选择框，选一张图当参考（改风格、换背景、重画） |
| **截屏** | **等你自己截一张**，助手自动接住 |
| **用上次的图** | 接着上一张参考图再生成（改提示词重画时用） |

选完（或截屏收到后）会弹出输入条写提示词，**回车开始生成**。

**截屏是怎么工作的**：点「截屏」后助手进入等待状态，气泡上会告诉你截图存到哪个目录
（默认桌面）。然后你**用平时习惯的方式截图** —— ⇧⌘4、微信、Snipaste 都行 ——
只要它落盘，助手就自动接住并弹出输入条。

> 为什么不自己做截图：那样需要「屏幕录制」权限，又是一个系统授权框。
> 你有自己的截图习惯，助手只要接住就行，不用再学一套、也不用再授权一次。
>
> 注意：**只把图放剪贴板**的截图方式（比如某些工具默认 Ctrl+C）收不到，
> 要让截图**保存成文件**。

参考图会先缩到长边 2048 像素再发（截图动辄 3000+ 宽，原样上去请求大得离谱）。

---

**没插件时的参数**：圆环 →「参数」里改的**模型 / 尺寸 / 张数**直接写进助手自己的配置
（`~/.huanmeng-ring.json` 的 `config.api`），立刻生效。
张数是「挨个调 N 次」，会花 N 份额度 —— 菜单上标着「×N 张」，看清楚再选。

## 四、出问题先看自检

**菜单栏 ◎ → 自检…** —— 检查 7 项，每项都告诉你**怎么修**。

### 辅助功能列表里找不到这个程序

按顺序做，一般第 1 条就好了：

1. **把「系统设置」整个退出（⌘Q）再重新打开** ——
   那个列表是窗口打开那一刻加载的，新登记的程序不会自己冒出来
2. 点菜单栏 **◎ →「⚠️ 点这里授予辅助功能权限」**
3. 还不行：`tccutil reset Accessibility com.huanmeng.ring`，再点一次菜单栏那行

> 列表里显示的名字是 **`HuanmengRing`**（文件名），
> 不是菜单栏看到的「幻梦圆环」—— 两个名字不一致，按文件名去找。

### 没有这个权限也能用

`⌥⌘R` 完全不受影响，只是 `⌥右键` 那一招用不了。

## 五、偏好设置

菜单栏 **◎ → 偏好设置…**（⌘,）。顶部是**实时预览**，改完立刻生效，关窗自动保存。

- **外观** —— 环大小 / 厚度 / 间隙 / 弹出距离 / 透明度 / 动画 / 投影 / 字号 / 全套配色（5 套预设）
- **交互** —— 热键 / ⌥右键开关 **及其作用范围** / 悬停高亮 / 数字键 / Esc / 方向线
- **内容** —— 六个扇区的**重命名 · 显隐 · 排序**
- **高级** —— 端口 / 配置文件位置 / 导入导出 / 恢复默认

## 六、卸载

双击 **`一键卸载.command`** —— 停掉自启、删掉 App、清掉配置。

## 附：在 Photoshop 里用（可选）

需要那台电脑上装 **UXP Developer Tool**（Adobe 的免费工具）。

装好 UDT → `Add Plugin` → 选包里的 `插件/Dream-ps-ai` → `Load`，
然后在 PS 里打开 **插件 → 幻梦AI 修图插件**。

> 为什么不能像普通软件那样双击装进 PS：UXP 插件的官方分发格式（`.ccx`）
> 需要 Adobe 的开发者签名，个人分发的包只能这样加载。
