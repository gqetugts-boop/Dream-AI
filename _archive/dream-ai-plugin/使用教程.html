Dream AI 创意助手 · 使用教程

Photoshop UXP Plugin · v1.0.0

安装 配置渠道 生图 回写 工具箱 本地引擎 画廊 批处理 语言与主题 常见问题

一、安装插件

  1. 在 Creative Cloud 桌面端安装 UXP Developer Tools。
  2. 打开 Photoshop。建议 24.0 及以上版本（原生生成式填充需要更高版本）。
  3. 启动 UXP Developer Tools，点左上角 Add Plugin，选择本插件目录里的 manifest.json。
  4. 在列表里点 Load 加载插件。
  5. 回到 Photoshop，菜单 增效工具（Plugins）→ Dream AI 创意助手 即可打开面板。建议把它拖到右侧面板组里长期停靠。
面板宽度：左侧导航栏固定 68px，右侧主区自适应，把面板拖到 任意宽度都不会错位；窗口特别窄（< 310px）时侧栏会只保留图标。

二、配置服务渠道

打开面板后点右上角的 设置 进入设置页，展开 服务渠道： 每个渠道填 接口地址 与 API 密钥，点 测试连接 会返回可用模型数量，并把模型列表缓存到生图页的下拉框里。

渠道默认地址密钥形态说明
Photoshop 原生—不需要直接调用 PS 生成式填充
OpenAI 兼容https://api.openai.com/v1sk-...任何兼容网关都可填这里
xAI 官方https://api.x.ai/v1xai-...图像与对话
自建 Grok 网关http://127.0.0.1:8000/v1g2a_...本地自建，支持异步轮询

地址填根地址或带 /v1 的地址都可以，插件会自动规范化。密钥只保存在本机 localStorage 的 dream-ai:settings 里，不会上传到任何地方。

三、开始生图

  1. 在 Photoshop 里用选区工具圈出要处理的范围（想要整图效果就不必框选）。
  2. 打开 生图 页，点 读取选区，上方会出现选区预览与像素尺寸。
  3. 选择模式：文生图 或 选区图生图。
  4. 自己写提示词。插件不提供内置词库，写什么完全由你决定。
  5. 按需添加参考图（最多 4 张）：可以 用当前选区 或 上传图片。
  6. 选好渠道、模型、尺寸、数量，点 开始生成。

提示词输入

  • 提示词框右下角显示字数，上限 5000 字；插件不对内容做任何预设或补全。
  • 在设置里可以配置 全局正向/负向提示词，会自动拼接进每次生成， 适合固定画风与固定禁忌。
  • 负向提示词默认收起，勾选左侧开关即可展开。

四、结果回写 Photoshop

默认开启自动回写：任务完成后结果会作为新的像素图层落到原文档的原位置。 回写参数在生图页的 回写 Photoshop 卡片里调整：

选项作用
生成后自动回写关掉后只在画廊里保留结果，需要手动回写
回写前自动校色把回图色彩向原图/选区的低频色彩对齐，减少偏色
屏幕混合适合辉光、光效类结果，与下层叠加而不是覆盖
边缘羽化给回写图层加羽化蒙版，弱化拼贴痕迹
回写目标按读取选区时记录的文档 ID 定位，不会贴错文档。如果那个文档已经关闭， 插件会直接报错停止，而不是把图贴到当前文档上。

五、工具箱

工具箱 页汇总了本地算法与常用操作，顶部标签切换：

工具用途
辉光多尺度辉光，含柔白、闪耀、星芒、宽银幕等风格，写回为屏幕混合图层
位移特效热浪 / 气流 / 刀光 / 涟漪四类位移场，可调强度、范围、羽化、噪声细节
色彩融合把回图色彩统计对齐到参考图，可选 Lab 均值方差、直方图、Reinhard、柔光、仅亮度
示波器亮度波形、分量波形、直方图、矢量示波器，支持实时取样
常用操作取消选区、复制图层、反选、前景色填充、自由变换、合并可见、拼合图像

辉光与位移特效的流程都是：读取选区 → 预览 → 写入文档。 预览不会改动文档，满意后再点写入。

六、本地引擎（ComfyUI / Forge）

ComfyUI

  1. 启动 ComfyUI（默认端口 8188），确认插件里的地址一致。
  2. 在 ComfyUI 里搭好工作流，用 导出（API 格式） 保存 JSON。
  3. 在插件 ComfyUI 页粘贴 JSON 或导入文件，点 校验工作流。
  4. 有选区时点 读取选区：插件会上传图片并自动注入 LoadImage 节点。
  5. 点 开始生成，进度会在状态条与页面里同步。
如果导入的是界面格式工作流（含 nodes 数组），校验会直接提示需要 API 格式，避免跑起来才发现没有输出。

Forge / SD WebUI

需要以 --api 参数启动 WebUI（默认端口 7860）。插件支持文生图与图生图、 采样器与步数、CFG、降噪强度、批次、LoRA（可叠加多个）、ControlNet（可叠加多个）， 并提供 1 秒一次的进度轮询与中断。

七、画廊

关于提示词：插件不内置任何提示词库，也没有"官方推荐提示词"。 提示词完全由你自己编写，插件只负责把它送到你选择的渠道。 如果想把常用的提示词存起来，可以在 Forge 页点 保存为预设， 它会作为你自己的条目存到本地（最多 50 条），不会随插件分发。

画廊

  • 每张生成结果都会自动归档，缩略图墙可直接点开查看。
  • 支持 回写 PS（按当前选区落图）、下载、复用提示词、删除。
  • 保留策略可选按数量、按天数或两者同时限制，也可以在设置里立即清理。

八、批处理

  1. 打开 批处理 页，在下方填写提示词、选择渠道与数量，点 加入批处理。
  2. 重复添加多条任务。
  3. 点 开始批处理，插件会串行执行并逐条更新状态。
  4. 需要时点 停止，已完成的条目保留，未开始的不再执行。
并发数在设置里控制（默认 1）。Photoshop 的模态操作是串行的，把并发调高并不会 让回写变快，只会让排队更长。

九、语言与主题

  • 侧栏底部的 中 / EN 按钮一键切换界面语言，立即生效，无需重启。
  • 侧栏底部的 ◐ / ☀ 按钮切换亮色与暗色主题。
  • 也可以在设置页里显式选择语言、主题与界面缩放（0.8×–1.6×）。

十、常见问题

点“读取选区”提示没有选区

请先在 Photoshop 里建立选区。如果选区只有几个像素，插件会判定为无效。 另外确认当前有打开的文档，且文档不是索引色/位图模式。

生成成功但没有回写到文档

  • 检查回写卡片里的 生成后自动回写 是否被关掉。
  • 查看底部状态条右侧的活动日志，回写失败会写明原因。
  • 如果读取选区后关闭了那个文档，回写会被拒绝（这是刻意的保护）。

结果颜色和原图不一致

打开 回写前自动校色。校色会把回图的色彩统计对齐到原图选区， 对“AI 回图整体偏亮/偏暖”这类问题效果最明显。也可以到工具箱用 色彩融合 手动做一次，并挑选更合适的算法。

通道测试连接失败

  • 自建网关要确认服务已启动，地址里的端口正确。
  • 密钥形态要对：Grok 网关是 g2a_ 开头，xAI 是 xai- 开头。
  • 401/403 表示密钥无效；429 表示触发限流，稍后再试。

ComfyUI 一直不出图

  • 先在 ComfyUI 界面里用同一个工作流跑通一次。
  • 确认导出的是 API 格式，不是界面格式。
  • 工作流里要有 LoadImage 节点，插件才能把选区图传进去。

面板里的滑块/色板点不动

这是自绘控件（UXP 的原生滑块与取色器无法控制样式），拖动滑块轨道即可； 色板可直接在十六进制输入框里粘贴颜色值。

面板太窄，内容被压扁

插件针对竖排窄面板做了断点适配：参数会从两列变一列、次要文字会收起。 如果仍然觉得挤，可以把面板拖宽，或在设置里把界面缩放调到 1.0 以下。
