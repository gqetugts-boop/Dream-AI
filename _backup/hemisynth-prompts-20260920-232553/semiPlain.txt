# 漫展现场 · 简单布景提示词（保留漫展背景 · 只加地面效果+周围道具）

> 用途：把一张 Cosplay 漫展实拍图做"现场布景化"——在保留原图漫展背景与人物、人物身上的光 100% 不变的前提下，只在人物脚下/周围的地面做效果、摆放主题道具物件（含少量浮空环绕物），并让它们与现场光线一致、产生真实接触阴影，像在漫展现场给 coser 简单搭出来的场照。
> 关键：不替换背景——漫展就是漫展，背景原样保留，新道具只叠在它前面。

任务：给一张 Cosplay 漫展实拍图做"现场布景化"——在【保留原图人物、原漫展背景 100% 不变】的前提下，在人物脚下/周围生成【主题地面效果、地面道具摆件、少量浮空环绕元素】，并让这些新增物与人物、与地面之间产生【投影与接触阴影】，使整张图看起来像"在漫展现场为这位 coser 简单布置了一个主题小场景"。【关键：新增的地面/道具/浮空物全部是照片级写实真实材质，绝不是塑料/PVC/CG/插画质感】——因为人物是实拍真人、背景是真实漫展现场，新增物必须同为真实质感，做到"真人站在漫展里真实布置的道具中"，而非"真人混进塑料玩具堆或 CG 贴图里"。

【★ 与"换背景"的根本区别（必须守住）】
- 本任务【绝不替换、绝不重绘漫展背景】：背景里的场馆/展台/人群/灯光/墙面/地面远处等，全部原样保留不动。
- 只能在【人物脚下与周围的近处地面、以及人物四周的中近景空间】叠加新的地面效果与道具；新增物可以【叠在原背景前方形成遮挡】，但不得改动、替换、重画背景本身。
- 类比：就像在漫展现场，在 coser 脚边铺点道具、摆几样主题物件——背景还是那个漫展，只是脚下周围被布置了一下。

【地面效果 — 人物脚下与周围（本任务核心）】
- 在人物脚下/落脚区与周围近处地面，叠加与主题呼应的真实地面效果：铺一层石板/泥土/草地/落叶/积水/瓦砾/沙地/地毯/木板等（按填空或角色气质自动判定），材质【照片级写实】（真石头颗粒风化、真泥土湿感、真草叶脉络、真积水镜面倒影、真落叶质感）。
- 这层地面效果【叠在原漫展地面之上/之前】，覆盖人物脚周的近处地面区域，向四周与远处自然过渡、逐渐融回原背景地面（不做成一块生硬的"地毯边缘"，边缘自然消隐或被道具、虚化掩盖）。
- 【与脚部真实接触】：站立姿态→脚踏在新地面上、有真实接触与压痕/陷入感、脚下有接触阴影；腾空/单脚点地姿态→保持原姿态不动，地面在下方合理承接，不强行拽落地、不改姿态。
- 地面不出现任何文字/铭牌/品牌名，只做纯造型与材质。

【地面道具 — 脚周围的写实摆件】
- 在人物脚下/周围地面摆放与主题呼应的真实道具（按填空或自动判定）：断剑/机械残片/书本/油灯/花草/碎石/箱子/道具武器/生活小物等。
- 道具【允许适度遮挡人物下半身、可叠在原背景前方】，营造围绕包裹的近景层次。
- 道具【大小严格按下方"比例锚定"，对照人体真实比例】；为【写实材质】，与实拍人物、真实漫展背景同质；按原图/现场主光方向受光，在地面/彼此间投下真实投影。

【浮空元素 — 周围与上方（少量点缀，不喧宾夺主）】
- 人物周围/上方配置少量浮空环绕元素（按填空或自动判定）：飘落的花瓣/叶片、悬浮的羽毛/花枝/飘带、斜插的道具等，营造动态包围感。
- 浮空元素分前中后景、有近大远小层次，可适度遮挡人物边缘或叠在背景前，但【数量克制】——是现场小布景的点缀，不是铺满全屏的特效。
- 【严禁发光/光效类元素】：不添加任何自发光体、光晕、辉光、能量特效、魔法阵、霓虹光效、星芒、光斑、粒子光效等。所有浮空物都是【不发光的真实实体物件】（花瓣就是花瓣、羽毛就是羽毛，靠反射现场环境光而非自发光）。透明类（水花/水滴）可有真实透明折射质感，但不发光、不塑料。

【比例锚定 — 用人物身体当量尺，所有新增物按真实尺寸配比（关键·专治比例失调）】
- 【唯一比例基准 = 画面里的人物】：先以人物身体为标尺读出画面真实尺度——用头长、手掌、身高、脚长作参照，推算画面里"1米/1厘米大约多少像素"。所有新增物大小都对照这个人物尺度、按现实中相对人体的真实比例来定。
- 【每个物件都先问"它在现实中相对人有多大"再定大小】：书本≈比手掌略大；油灯/茶壶≈一到两个拳头；花瓣≈指甲到手指；蜡烛/瓶子≈手掌长；石块/瓦砾≈拳头到头部不等；剑/法杖≈与人身高相当或略长；箱子/礼物堆≈膝到腰高。
- 【透视缩放】：同一物件近大远小符合原图透视；前景可大、身后远处相应缩小，但"相对人体的真实比例"始终成立。
- 【严禁】：物件大小离谱（油灯比头大、花瓣像盘子、书本像门板）、道具与人不成比例、同类物件大小不统一、浮空物大到盖住人物主体。

【透视匹配 — 三维对齐（水平+垂直+俯仰）】
所有新增元素必须严格遵循原图的三维透视系统，分三个维度逐一对齐：

【① 水平方向透视（消失点与地平线）】
- 先找原图的【地平线高度】：通过人物站姿、背景建筑/展台边缘、地面延伸方向判断地平线在画面中的位置（低/中/高）。
- 识别【消失点方向】：地面道具、地面效果的透视线（物体边缘延长线）必须汇聚到与原图相同的消失点——单点透视（正面）、两点透视（斜角）、或三点透视（仰俯视）。
- 【落地物的水平透视】：所有地面道具（书堆/箱子/花丛/石块等）的底面、顶面、侧面的透视线，全部指向原图的消失点；近处物件大、远处物件小，缩放比例与人物到相机的距离一致。
- 【地面效果的水平透视】：地面纹理（花瓣/水面/光斑/裂纹）的透视变形（近疏远密、近大远小）必须与原地面的透视走向一致，绝不平铺、绝不与原地面透视矛盾。

【② 垂直方向透视（物体高度的透视缩放）】
- 【高度与距离的联动】：同样高度的物体，距离相机越远、在画面中显示越矮；近处的茶杯可能比远处的箱子在画面中更高——按原图的纵深透视，近处物体的视觉高度 > 远处物体。
- 【垂直线的透视】：平视或微俯视时，物体的竖直边缘（柱子/瓶子/剑）接近垂直但略有汇聚；强俯视时竖直线向下汇聚，强仰视时向上汇聚——必须与原图人物身体、背景柱子/展台的垂直线倾斜方向一致。
- 【悬空物的垂直位置】：少量浮空环绕物的高度（过腰/过胸/过肩）要体现透视：飘到人物身后的部分因距离变远而在画面中显得略低、略小。

【③ 俯仰角度透视（相机视角的三维匹配）】
- 【识别相机俯仰】：从人物的透视变形判断相机角度——
  · 平视：人物头部与脚部在画面中的视觉高度比例接近真实身高比例，地平线约在腰到胸高度。
  · 俯视：能看到人物头顶、肩膀上表面，地平线高（在胸部以上或画面外上方），地面占画面比例大。
  · 仰视：能看到人物下颚、鞋底，地平线低（腰部以下或画面外下方），背景天花板/上方结构占比大。
- 【新增物的俯仰透视适配】：
  · 俯视图：地面道具能看到顶面、上表面；悬空物从上往下看；物体底部离相机更近，在画面中占比更大。
  · 仰视图：地面道具看到底部、支撑面；悬空物从下往上看；物体顶部离相机更远，在画面中更小。
  · 平视图：地面道具主要看侧面、正面；悬空物与人物处于相近视平线，前后关系靠遮挡体现。
- 【三点透视的极端情况】：强俯视或强仰视时，不仅水平线有消失点，垂直线也有消失点（俯视向下汇聚、仰视向上汇聚）——新增物的所有边缘都要匹配这套三点透视，绝不出现"地面是俯视、道具却是平视"的透视断层。

【透视自检清单（成图前必过）】
✓ 地面道具的底面边缘延长线，汇聚到原图的地平线消失点（水平对齐）
✓ 同类物体近大远小的比例，与人物到相机的距离透视一致（纵深对齐）
✓ 物体的竖直边缘倾斜方向，与原图人物/背景的垂直线一致（俯仰对齐）
✓ 能看到物体哪些面（顶/底/侧），与原图的俯仰角度一致（视角对齐）
✓ 悬空物飘到身后的部分，因距离变远而略小、略低、略虚（景深对齐）

【严禁透视错误】
- 地面道具的透视线与原地面矛盾（消失点不同）
- 落地物"飘"在空中、底部与地面有缝隙、或歪斜倾倒
- 物体大小不符合其在空间中的位置（远处的反而比近处大）
- 俯视图里道具却呈现平视视角，或仰视图里道具呈现俯视视角
- 同一画面内不同道具使用不同的透视系统（各说各话）

【材质与画风统一 — 至高红线】
- 所有新增元素（地面/道具/浮空物）必须达到与【实拍人物、真实漫展背景同等的照片级写实度】：真实材质纹理、真实表面细节与瑕疵、真实光泽反射。
- 【严禁塑料感/PVC/CG渲染感/游戏建模感/插画感】——不要因为"布景/摆件"就做成塑料玩具或 CG 贴图，要做成"漫展现场真实摆着的道具"。
- 新增元素与人物、与漫展背景处于同一真实光照与空间，浑然一体；新增物与人物、与背景的衔接【无抠图硬边/无合成断层】，噪点颗粒/白平衡/色调与原图统一。

【光影融合 — 只做投影与接触阴影（绝不碰人物身上的光）】
- 严禁改变人物身上现有的受光/明暗/对比/色温——人物身上的光 100% 保持原样。
- 从人物身上（并参考漫展现场背景的光）【反推主光方向、软硬、色温】，新增道具全部按这套现场光来受光，不产生会落到人物身上的新光源、不给人物重打光。
- 只新增：①新增物在地面/彼此之间的投影；②人物脚部与新地面的接触阴影；③新增物落在地面/原背景前的投影。
- 所有新增投影的方向、软硬、色温严格遵循原图/现场主光，与人物身上原有阴影、与背景现有阴影逻辑一致。

【必须保留 — 红线】
- 人物本体（面部/五官/发型/服装/身体/姿态/以及人物身上的光）：100% 像素级不动，只加人物之外的地面效果/道具/浮空/投影。
- 原漫展背景：100% 保留不动（新增道具/浮空物可叠在其前方遮挡，但绝不重绘、不替换、不改画背景本身，包括场馆/展台/人群/灯光/远处地面）。
- 构图/画幅/相机视角/人物位置大小：不变，不裁切、不缩放人物。

【元素丰富度】
- 默认按角色气质定繁简；可在【角色属性】框附"简洁/适中/丰富/极繁"调整道具与浮空物密度。留空则适中、克制，作为现场小布景的点缀，不喧宾夺主、不糊住人物主体、不盖住漫展背景。

【失败判定（任一触发即重做）】
①该退回却硬做（半身/无脚部空间的图硬加了地面布景） → 失败
②【替换/重绘了漫展背景】而非在其前叠加（背景必须原样保留） → 失败（本任务核心红线）
③新增物呈塑料感/PVC/CG/插画感，与实拍人物、真实漫展背景质感脱节（核心失败） → 失败
④改动了人物本体，或改动了人物身上的光 → 失败
⑤新增道具/地面投影方向与原图/现场主光矛盾，或凭空产生会落到人物身上的新光源 → 失败
⑥腾空姿态被强行拽落地，或人物姿态被改 → 失败
⑦新增地面效果边缘生硬（像贴了块地毯），未与原背景地面自然过渡融合 → 失败
⑧地面/落地道具的透视与原图漫展地面/水平线矛盾、不在同一透视空间、与脚部落点不在同一水平面 → 失败
⑨比例失调——道具相对人体不成比例、与人不成比例、同类物件大小不统一、浮空物盖住人物 → 失败
⑩出现发光/光效/辉光/能量/魔法阵/星芒/光斑/粒子等发光元素 → 失败
⑪新增物带运动模糊/动态模糊/拖影/速度线（必须清晰静止对焦锐利） → 失败

⑬新增物与人物、与背景衔接有合成断层/抠图硬边 → 失败
