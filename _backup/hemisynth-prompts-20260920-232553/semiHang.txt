【★★★ 悬空环绕元素系统 — 空间感的核心技法（本提示词的灵魂）】
这是把"人贴在布景前"变成"人被场景包裹在空间里面"的关键手段。核心打法只有一个：【悬停环绕】。

【主打 · 带状环绕】——【长条连续的带状物】悬空绕着人物盘旋，这是环绕感的唯一正确形态：
- 【选材（按主题选合理的带状物）】：长飘带/绸缎带/绳索/铁链/花藤蔓/串珠链/注连绳/纱带/纸卷带……必须是现实存在的、与主题呼应的带状实体，照片级写实材质。
- 【环绕轨迹（核心中的核心）】：带状物以人物为中心【呈螺旋/圆环轨迹盘绕一至两圈】，带身连续流畅、有自然的翻卷与弧度起伏——想象一条长绸带绕着她慢慢飞了一圈半后静止在空中。
- 【前后穿插（环绕感的命）】：同一条带必须在画面中【穿过人物身前 → 绕到身侧 → 转到身后被她身体遮挡 → 再从另一侧绕出】——带被人物"切"成可见段与被挡段交替出现：身前段（近、宽、按景深轻微虚化、遮挡她身体局部）、身侧段（清晰、中等）、身后段（被她挡住只露出弧线两端、略小略虚）。观者顺着这条带能"读出它绕了她一圈"——这就是空间感。
- 【条数与层次】：1-3 条带为宜（一条主带盘绕最大最完整，可加一两条副带在不同高度反向/交错盘绕）；多条带高度错落（一条过腰际、一条过膝边或肩上方）、倾斜角度不同，绝不平行。
- 【带的物理】：绸带有飘卷的翻面与光泽变化、绳有垂坠张力、链有节段坠感、藤有叶与弧度、静止清晰无拖影。
- 【带的来源与身份（防"凭空出现"）】：每条环绕带必须【有出处、有身份】，观者一眼能读出"它是什么、为什么在这"——两种合法来源：①【从人物自身延伸】：她服饰上现有的缎带/发带/腰带/披帛的延长段飘出环绕（最自然，带与人物服装同色同材质）；②【从场景物件系出】：一端系在/连着场景道具（神社的铃绳、灯笼的挂绳、藤蔓从花丛长出）。凭空出现、与人物和场景都无关联的带子=失败。
- 【带宽铁律（防粗大）】：带必须纤细轻盈——缎带/飘带宽约【两三指至半个手掌】（严禁超过手掌宽）、绳约手指粗、链约拇指粗；带是缠绕人物的优雅线条，不是包裹人物的宽幅布匹/水滑道。宁细勿粗。
- 【小物点缀】：主题小物（铃铛/花朵/坠饰）可【系在带上/沿带的轨迹散布】少量悬停，作为带的配角——不做脱离带的大规模独立悬停阵。

【辅助 · 飘落点缀】——轻质物（花瓣/叶片/羽毛/雪花）自然飘落，填充环绕带之间的空间，数量克制。

【可选 · 垂落】——仅当悬空元素填空中明确写了"从上方垂下"的描述时才使用；没写就不做垂落，悬空预算全给带状环绕。

【严禁（环绕感的反面清单）】：
- 全部悬空物处在同一深度平面（贴纸墙）、同一高度（一条横线）、或全躲在人物身后/只堆在某一侧（没有环绕包围感）——【从成图上必须一眼读出"这些东西绕着她一圈"】，读不出=失败。
- 【材质与光】：照片级写实，按现场主光受光；身前近景件不在人物身上投明显阴影（保人物光不变）。
- 【红线】：不发光；不遮挡面部与胸口以上主体；身前件克制（1-3件，"透过前景看人"不是栅栏）。

【比例锚定 — 用人物身体当量尺】
- 【唯一比例基准 = 画面里的人物】：以头长/手掌/身高/脚长为标尺推算画面真实尺度，所有新增物按现实中相对人体的真实比例定大小。
- 参考：书本≈比手掌略大；油灯/茶壶≈一到两个拳头；花瓣≈指甲到手指；蜡烛/瓶子≈手掌长；石块≈拳头到头部不等；剑/法杖≈与人身高相当或略长；箱子≈膝到腰高。
- 【透视缩放】：近大远小符合原图透视，"相对人体的真实比例"始终成立。
- 【严禁】：物件大小离谱、同类大小不统一、悬空物大到盖住人物主体。

【透视匹配 — 三维对齐（水平+垂直+俯仰）】
所有新增元素必须严格遵循原图的三维透视系统，分三个维度逐一对齐：

【① 水平方向透视（消失点与地平线）】
- 先找原图的【地平线高度】：通过人物站姿、背景建筑/展台边缘、地面延伸方向判断地平线在画面中的位置（低/中/高）。
- 识别【消失点方向】：地面道具、地面效果的透视线（物体边缘延长线）必须汇聚到与原图相同的消失点——单点透视（正面）、两点透视（斜角）、或三点透视（仰俯视）。
- 【落地物的水平透视】：所有地面道具（书堆/箱子/花丛/石块等）的底面、顶面、侧面的透视线，全部指向原图的消失点；近处物件大、远处物件小，缩放比例与人物到相机的距离一致。
- 【地面效果的水平透视】：地面纹理（花瓣/水面/光斑/裂纹）的透视变形（近疏远密、近大远小）必须与原地面的透视走向一致，绝不平铺、绝不与原地面透视矛盾。

【② 垂直方向透视（物体高度的透视缩放）】
- 【高度与距离的联动】：同样高度的物体，距离相机越远、在画面中显示越矮；近处的茶杯可能比远处的箱子在画面中更高——按原图的纵深透视，近处物体的视觉高度 > 远处物体。
- 【垂直线的透视】：平视或微俯视时，物体的竖直边缘（柱子/瓶子/剑）接近垂直但略有汇聚；强俯视时竖直线向下汇聚，强仰视时向上汇聚——必须与原图人物身体、背景柱子/展台的垂直线倾斜方向一致。
- 【悬空物的垂直位置】：带状环绕物、悬停小物的高度（过腰/过胸/过肩）要体现透视：绕到人物身后的部分因距离变远而在画面中显得略低、略小。

【③ 俯仰角度透视（相机视角的三维匹配）】
- 【识别相机俯仰】：从人物的透视变形判断相机角度——
  · 平视：人物头部与脚部在画面中的视觉高度比例接近真实身高比例，地平线约在腰到胸高度。
  · 俯视：能看到人物头顶、肩膀上表面，地平线高（在胸部以上或画面外上方），地面占画面比例大。
  · 仰视：能看到人物下颚、鞋底，地平线低（腰部以下或画面外下方），背景天花板/上方结构占比大。
- 【新增物的俯仰透视适配】：
  · 俯视图：地面道具能看到顶面、上表面；悬空物从上往下看、能看到带状物的上表面；物体底部离相机更近，在画面中占比更大。
  · 仰视图：地面道具看到底部、支撑面；悬空物从下往上看、看到带状物的下表面；物体顶部离相机更远，在画面中更小。
  · 平视图：地面道具主要看侧面、正面；悬空物与人物处于相近视平线，前后关系靠遮挡体现。
- 【三点透视的极端情况】：强俯视或强仰视时，不仅水平线有消失点，垂直线也有消失点（俯视向下汇聚、仰视向上汇聚）——新增物的所有边缘都要匹配这套三点透视，绝不出现"地面是俯视、道具却是平视"的透视断层。

【透视自检清单（成图前必过）】
✓ 地面道具的底面边缘延长线，汇聚到原图的地平线消失点（水平对齐）
✓ 同类物体近大远小的比例，与人物到相机的距离透视一致（纵深对齐）
✓ 物体的竖直边缘倾斜方向，与原图人物/背景的垂直线一致（俯仰对齐）
✓ 能看到物体哪些面（顶/底/侧），与原图的俯仰角度一致（视角对齐）
✓ 悬空物绕到身后的部分，因距离变远而略小、略低、略虚（景深对齐）

【严禁透视错误】
- 地面道具的透视线与原地面矛盾（消失点不同）
- 落地物"飘"在空中、底部与地面有缝隙、或歪斜倾倒
- 物体大小不符合其在空间中的位置（远处的反而比近处大）
- 俯视图里道具却呈现平视视角，或仰视图里道具呈现俯视视角
- 同一画面内不同道具使用不同的透视系统（各说各话）

【材质与画风统一 — 至高红线】
- 所有新增元素达到与实拍人物、真实漫展背景同等的照片级写实度：真实材质纹理、表面瑕疵、光泽反射。
- 【严禁塑料感/PVC/CG渲染感/游戏建模感/插画感】。
- 新增元素与人物、背景处于同一真实光照与空间；衔接无抠图硬边/无合成断层，噪点颗粒/白平衡/色调与原图统一。

【光影融合 — 只做投影与接触阴影（绝不碰人物身上的光）】
- 严禁改变人物身上现有的受光/明暗/对比/色温。
- 从人物与现场反推主光方向、软硬、色温——新增物全按这套光受光，不产生落到人物身上的新光源。
- 只新增：①新增物之间与地面上的投影；②人物脚部与新地面的接触阴影；③低处悬停物的悬空投影。方向软硬色温与原图主光一致。

【必须保留 — 红线】
- 人物本体（面部/五官/发型/服装/身体/姿态/身上的光）：100% 像素级不动。
- 原漫展背景：100% 保留不动（新增物可叠其前方遮挡，绝不重绘替换背景本身）。
- 构图/画幅/相机视角/人物位置大小：不变，不裁切不缩放人物。

【失败判定（任一触发即重做）】
①该退回却硬做（半身/无脚部空间硬加布景） → 失败
②替换/重绘了漫展背景 → 失败（核心红线）
③新增物呈塑料/PVC/CG/插画感 → 失败（核心失败）
④改动了人物本体或人物身上的光 → 失败
⑤投影方向与现场主光矛盾，或产生落到人物身上的新光源 → 失败
⑥腾空姿态被拽落地、人物姿态被改 → 失败
⑦地面效果边缘生硬未融回原地面 → 失败
⑧透视与原图地面/水平线矛盾 → 失败
⑨比例失调、同类大小不统一、悬空物盖住人物 → 失败
⑩出现发光/光效/辉光/魔法阵/星芒/粒子等发光元素 → 失败
⑪新增物带运动模糊/拖影/速度线 → 失败
⑫出现文字/铭牌/品牌名乱码 → 失败
⑬衔接有合成断层/抠图硬边 → 失败
⑭密度失控（件数与档位明显不符、道具糊脸） → 失败
⑮【无环绕感】带状物没有绕人物盘旋（只是横穿画面/贴在一侧/全在身后或身前）、同一条带读不出"前-侧-后"的穿插遮挡、带身断裂不连续——成图必须能顺着带读出"它绕了她一圈" → 失败

【至高红线】在保留原图人物（含其身上的光）与原漫展背景 100% 不变的前提下，按六个输入框（布景主题/地面效果/地面道具/悬空元素/道具密度/角色属性）在人物脚下与周围生成主题地面效果、写实道具，并按【悬空环绕元素系统】布置【带状环绕物——1-3条与主题呼应的带状实体（飘带/绳索/锁链/花藤等）以人物为中心螺旋盘绕一至两圈，同一条带穿过身前（宽大微虚遮局部）、绕到身侧（清晰）、转入身后（被她遮挡）再绕出——顺着带能读出"它绕了她一圈"是唯一验收标准】；主题小物只作带上点缀；垂落物仅填空点名才用；只新增投影与接触阴影使其融入现场；所有新增物照片级写实、不发光、无运动模糊、透视对齐、以人物为量尺、密度按档位、绝不重打人物光、绝不替换背景、任何档位不遮脸。最终="同一个真人、同一个漫展背景、同一套光——一条飘带绕着她盘旋而过，脚下有地、身边有物、身周有带状环绕的前后穿插，人在场景的正中心，而不是贴在布景前"。
